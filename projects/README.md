## 工具列表

### 🎮 [FIRE 模擬器](https://kikopapa.github.io/projects/fire-simulator.html)

用遊戲體驗「被動收入 ≥ 總支出 = 財富自由」。靈感來自經典的現金流桌遊，機制與內容為原創，場景採台灣薪資與房價。
**適合**：想學財商的大人、親子、課堂

* **玩法**：選職業（國小老師、軟體工程師、住院醫師）→ 每月抽一張卡 → 決定買資產、分期、借款或放棄
* **你會看到**：收入表、支出表、資產與負債清單、本月現金增減長條圖、財富自由進度條
* **可學到**：資產 vs 負債、淨現金流、槓桿風險、緊急預備金、消費誘惑與詐騙警訊
* **存檔**：進度存在瀏覽器（localStorage），換裝置或清除瀏覽資料後不會保留

> 數字為簡化設定，僅供教學，不構成投資建議。

### 🎮 [FIRE 模擬器-小孩版本 ( 種出我的錢果樹 ) ](https://kikopapa.github.io/projects/kids-money-tree.html)
* 每週抽一張卡 → 決定買資產、打工、買想要的東西，或先存起來
* 你會看到：我的錢包、樹和鵝的成長進度、本週現金變化、欠爸媽的錢
* 可學到：資產要慢慢養大、用時間換錢 vs 讓錢幫你工作、想要 vs 需要、借錢要付利息、遇到詐騙怎麼辦

### 🎯 [2030 願景畫布](https://kikopapa.github.io/projects/fire-target-2030.html)
把 2030 年的目標視覺化，放在部落格選單中，幫助自己持續對焦。
**適合**：想盤點人生與財務目標的人

### 🎯 [數位游牧新手清單]([https://kikopapa.github.io/projects/fire-target-2030.html)
自由工作者新手清單，36 個檢查項，勾選進度
**適合**：想從上班族轉為自由工作者

### 🪙 [兒童理財課(財商圖卡系列)](https://kikopapa.github.io/projects/kids-finance-gallery.html)

親子一起用的財商內容，把理財觀念變成孩子容易理解的畫面。
**適合**：親子財商教育

### 🗺️ [兒童圍棋學習冒險地圖](https://kikopapa.github.io/projects/go-learning-map-plus.html)

把兒童圍棋的學習路徑做成地圖，讓孩子看得到自己走到哪裡、下一站去哪。
**適合**：學圍棋的孩子與家長

### ♟️ [圍棋棋風小測驗](https://kikopapa.github.io/projects/shilin-bridge-go-quiz.html)

搭配文章<士林橋下的圍棋時光>製作的圍棋互動測驗，邊玩邊認識台北免費下圍棋的好去處。
**適合**：圍棋愛好者、想挑戰的朋友

### 🌌 [宇宙能源尺](https://kikopapa.github.io/projects/kardashev-scale-interactive.html)

以卡爾達肖夫指數（Kardashev scale）為基礎的互動工具，從「文明等級」的角度，看人類目前走到哪一步。搭配文章<我們連第 1 級文明都還不是？>。
**適合**：對科普與宇宙有興趣的人
